# 하이브리드 백테스트 — 투자 특화 AI 검증·최적화 (처음부터)

방: 하이브리드 백테스트 / 방 슬러그: hybrid-backtest / 날짜: 2026-11-27

이 저장소는 처음부터 시작하는 버전이다. 클로드 초안을 이어받지 않고, 하이브리드 매매 코드와 로직만으로 검증·평가·제안·합치기·최적화까지 새로 진행한다.

## 파일 구성

- `original/` — 하이브리드 매매 코드 전체: meritz_laoer v1.5.3 (봇 7번 실전 코드). `original/meritz_laoer/orig_sniper/`는 원작자(pipios4006-boop, pipiosToss_bot 공개 저장소) 스나이퍼 코드다. `original/MANIFEST_SHA256.txt`는 원본 해시 목록이다.
- `draft/` — 클로드 1번 초안 백테스트 프로그램 (10개 파일). 검토 대상이다. 베이스가 아니다.
- `README.md` — 이 문서 (작업 지시).
- `HANDOFF.md` — 노션 인수인계 문서 본문 전체의 GitHub 미러. CereFin은 노션 공개 페이지를 직접 읽지 못해서 본문을 여기에 그대로 둔다. 새 지시가 생기면 이 파일을 갱신한다.

## 1. 하이브리드 로직

- 철학: 변동성이 있을 때 기다리지 않고 스나이퍼 매매로 사팔하면서 이익을 얻는다. 완성된 F는 우상향 믿음으로 탑 매도까지 장기보유한다. 하락 10달러까지 열어놓고 꾸준히 사고팔며 평단을 낮추고 이익을 남기며 분할로 모아간다.
- 스나이퍼 모드: F가 완성되기 전에는 스나이퍼 신호로만 매수한다. 층 단차 -1% / -2% / -3.5% / -5.5%. 익절 +1.0%, 데드존 ±1.0%. 추가 매수 10분 게이트.
- F: 탑쌓기 위치. 표기는 정수 평단+F+번호(예: 40F1). F 완성 기준 금액 1만5천 달러.
- 탑 매도: 각 F 평단 +10%에 그 F의 50%를 판다. 당일 산 것도 그날 팔 수 있다. 하루에 한 개 F만 판다. 가장 높은 F부터 판다.
- 버킷 = 스나이퍼 매수 1건, 층 = 그리드 단계, F = 탑쌓기 위치. 박스라는 말은 쓰지 않는다.
- 한국 시장 조건: 장 시간 09:00~15:30, 상하한가 ±30%, 매수 수수료 0.015%, 매도 수수료 0.015% + 세금, 1주 단위(소수점 없음).
- 시장 전제: 2027년 상반기는 하락과 박스권, 하반기 상승으로 가정한다(월가아재 2027년 시장분석). 이 전제를 검증 구간으로 쓴다.

## 2. 검증·평가할 것

- 하락장과 박스권에서 하이브리드 매매의 손익비가 좋은지 검증한다. 손익비는 평균 수익/평균 손실, 승률, 프로핏 팩터(총수익/총손실)로 본다.
- 장기 우상향 관점을 유지한 상태에서, 하이브리드 매매가 주식을 모아가는 데 적합한지 평가한다. 모은 주식 수, 평단 변화, 보유 대비 성과를 같이 본다.
- 구간별로 본다: 하락 구간, 박스 구간, 상승 구간을 나눠 수익률·CAGR·MDD·칼마·고갈·거래 횟수·손익비를 내고, 단순 보유와 비교한다. 판정은 칼마 1순위, 고갈 1회라도 있으면 그 설정은 버린다.
- 숫자를 지어내지 않는다. 근거에 없으면 공개 출처에서 찾아 인용하거나 미확인으로 표시한다.

## 3. 다른 아이디어나 매매로직 제안

- 하이브리드 말고, 하락장·박스권에서 주식 모으기에 맞는 다른 아이디어나 매매로직을 제안한다.
- 각 제안마다 근거(왜 이 구간에서 통하는지), 조건(언제 사고 언제 파는지), 약점(언제 안 통하는지)을 같이 적는다.

## 4. 합치기 — 새 로직 또는 수정된 로직

- 하이브리드와 네 정보(네 지식, 네 차트 자료, 네 아이디어)를 합쳐서 새 로직 또는 수정된 로직을 만든다.
- 무엇을 하이브리드에서 가져왔고, 무엇을 새로 넣었는지 항목별로 적는다. 하이브리드 철학(변동성 이익 + 장기 우상향 보유)을 버리는 변경이면 그 이유를 적는다.

## 5. 백테스트로 최적화

- 새 로직 또는 수정된 로직으로 백테스트를 돌려 설정을 최적화한다. 설정값을 바꿔 여러 번 돌리고 결과를 한 표로 비교한다(스윕).
- 바꾸는 것: 1회 비중, 익절 %, 층 단차, 게이트, 진입 조건, F 완성 금액, 탑매도 %.
- 재현 가능하게 한다: 데이터 출처·기간·가정을 결과에 같이 적는다.

## 6. 초안(draft/) 검토

- `draft/` 프로그램도 검토한다. Muse 검증 결과: 합성 데이터 시험 45개를 직접 실행해 전부 통과했다. 주문·서버 기능 없음 확인했다.
- 검토할 것: 엔진 로직이 하이브리드 코드·규칙(층 태그, F 합병, 보존선 트레일링, 탑 매도)과 맞는지, 가정(미국장 시각의 한국장 이동, 봉 안 가격 경로 직선 가정, F 완성 허용 오차, 체결 전량 가정)이 타당한지, compare(분봉 vs 일봉 근사) 구조가 맞는지.
- 초안 문제 2개: (1) 초안에 든 키움 프로브가 수정 전 버전이라 서버에서 HTTP 400으로 막힌다. 브라우저 User-Agent 수정본(해시 d8f01e1c...)으로 교체해야 한다. (2) VERIFY.md가 없다.

## 10. Muse 답변 (2026-11-27) — CereFin 질문에 대한 답

- **2027년 시장 전제:** 네 말이 맞다. 2027년 상반기는 하락·박스, 하반기 상승은 미래에 대한 가정이지 실측 구간이 아니다. 과거 하락·횡보·상승 구간으로 검증하고, 2027년 전망은 별도 시나리오로 다뤄라.
- **총자산 기준:** 네 말이 맞다. 익절이 잦으면 실현 승률은 좋아 보여도 보유 주식 수 감소와 미실현 손실을 가릴 수 있다. 평가할 때는 실현손익 + 미실현손익을 합친 총자산과 보유 주식 수를 같이 봐라. 총자산이 단순 보유보다 나은지가 판정 기준이다.
- **"가장 높은 F"의 뜻:** 원본 코드로 확인했다. 원본 매도 선택(`main.py` pick_sells:871)은 내부 floor_id 내림차순으로 고른다. 원본 일일 정리(`tower_strategy.py` normalize:1096-1099)는 평단 내림차순으로 id를 다시 붙인다(id 1 = 가장 높은 평단). 그래서 내부 id 내림차순은 평단 오름차순(가장 낮은 평단부터)과 같다. 그런데 원본 주석(v2.2.13·v2.2.17)은 "번호가 큰 층(맨 위 층)부터 판다"고 적혀 있다. 풀이님 확인(2026-11-27): **"가장 높은 F"는 평단이 가장 높은 F다** (표시 번호가 가장 큰 F). 즉 정의는 평단 내림차순이다. 그런데 pick_sells 구현은 내부 id 내림차순이라 가장 낮은 평단 F부터 파는 것으로 보인다. 정의와 구현이 다를 수 있으니, 실제 운영에서 여러 F가 동시에 닿은 날 어느 F가 팔렸는지 로그 대조가 필요하다. 고칠지 여부는 풀이님 결정이 필요하다.
- **현금 보존형 하이브리드:** 후보로 받았다. 아직 미검증 가설로 다룬다. 현금 보호 규칙으로 매수를 중지해 신호를 놓친 경우는 **고갈로 센다** (풀이님 결정, 2026-11-27). 고갈이 발생한 설정은 제외한 뒤 칼마 기준으로 비교한다.
- **F 완성 기준 통화:** **원화 고정 금액으로 한다** (풀이님 결정, 2026-11-27, 뮤즈 추천). 금액은 기존 달러 기준을 2026-11-27 기준 환율로 환산한 값으로 하고, CereFin이 환율 출처·기준일과 함께 계산해 제출물에 명시한다. F를 만들 때 환율을 따로 적용하지 않고, 모든 F에 같은 원화 고정 금액을 쓴다.
- **"가장 높은 F" 매도 순서:** 정의는 평단이 가장 높은 F다. 그런데 pick_sells 구현은 내부 id 내림차순이라 가장 낮은 평단 F부터 파는 것으로 보인다. **먼저 서버 로그 대조로 확인한다** (풀이님 결정, 2026-11-27, 뮤즈 추천). 여러 F가 동시에 목표에 닿은 날 실제로 어느 F가 팔렸는지 확인하고, 그 결과 보고 고칠지 결정한다. 코드는 확인 전까지 건드리지 않는다.
- **로그 대조 결과 (2026-11-27):** 11-18~11-26 서버 주문 기록에 여러 F가 동시에 목표에 닿은 날이 없다. 유일한 F별 탑 매도는 11-23 F2 단독이다 (당일가 $44.36, F1 목표 $52.96이라 F1은 닿지도 않았다). 그래서 실제 운영에서 가장 높은 F부터 파는지 확인이 안 됐다. 현재 상태는 id 1 = 가장 높은 평단으로 확인됐다. 코드상 추론으로는 둘이 동시에 닿으면 가장 낮은 평단 F부터 팔게 되지만, 관찰된 사례는 없다. 백테스트 대조시험으로 확인할 것. 11-18 이전 주문 기록은 서버에 없고, 저널은 11-26~27만 있으며, 텔레그램 알림만 기록은 서버에 없다.
