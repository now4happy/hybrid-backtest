# 키움 분봉 — 종목별·월별 분할

원본 4개 파일(`data/kiwoom_minute/*.csv`)을 종목별·월별로 나눈 것이다. 원본 파일은 그대로 둔다.

- 파일명: `<종목>_1m_<연도>-<월>.csv` (예: `005930_1m_2025-11.csv`)
- 각 파일 첫 줄은 원본과 같은 헤더(`time,open,high,low,close,volume`)다. `time`은 `YYYYMMDDHHMMSS`다.
- 원본 파일명·기간·행 수·해시는 `MANIFEST_SHA256.txt`에 있다.
- 기간: 2025-11-03 ~ 2026-11-27 (프로브 실행일 기준). 종목: 005930 삼성전자, 000660 SK하이닉스, 229200 KODEX 코스닥150, 132030 KODEX 골드선물(H).
